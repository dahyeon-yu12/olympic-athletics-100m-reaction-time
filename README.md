# olympic-athletics-100m-reaction-time
Data and code for the analysis of reaction time changes in 100m sprinters after the 2010 false start rule change
## Data Source

The reaction time data were obtained from the following open dataset:

- Mirshams Shahshahani, P. (2018). *Downloaded IAAF Sprint Results in all Heats for 2004 - 2016 Olympics for both Men and Women* [Data set]. University of Michigan - Deep Blue Data. https://doi.org/10.7302/Z20V8B11

The original data were collected from the IAAF (now World Athletics) results pages.

## Related Paper

- Mirshams Shahshahani, P., et al. (2018). PLOS ONE. https://doi.org/10.1371/journal.pone.0198633
